# Sophia Compute

The agents you hire, and the equipment they use: an assistant in every workspace, custom agents in isolated sandboxes, and any model you choose.

- An assistant that reads, or reads and edits, with a record of every change
- Your choice of model, with the price of every reply shown
- Custom agents that run on a schedule
- Your own model key on your own install

*Shipped · next release 1.0.1*

## Agents

| Item | What it is | Status |
| --- | --- | --- |
| Search by meaning, computed on the server | Finding documents by meaning rather than exact words runs on the customer's own server with an open model. No outside AI service or key is needed for it. | Shipped |
| Agent memory | Agents connected to a workspace can write down what they learned, with a pointer to where they learned it, and look it up later. People do not see a memory screen; the memory surfaces as ordinary documents. | Shipped |
| Choice of AI model ('voices') with the price shown | People pick which AI model answers them from a large list. Each model shows its price, and every reply is marked with the model used and what it cost. | Shipped |
| One home for all conversations: Continue and Save to Sophia Desk | All of a person's chats sit in one list, newest first. Any old chat can be reopened and continued with the same or a similar model, saved as a normal document in a workspace, or downloaded as Markdown. | Shipped |
| Record of what the assistant changed | Under every reply, the panel lists what the assistant changed and links each change to the document's history. When it deletes something, a permanent receipt is written first. | Shipped |
| Workspace chat that can read, or read and edit | Every workspace has a chat panel. People who can edit the workspace get an assistant that can also edit it on their behalf; people who can only view it get one that can only read and search. | Shipped |
| Agent triggers (schedules and chat apps) | Agents can run on a schedule or when mentioned in Discord. They cannot yet be started from Slack, Microsoft Teams, email or a webhook. | Shipped · set up at install |
| Custom agents in isolated sandboxes | We can set up a purpose-built AI agent for a team, for example one that watches a channel and answers from your documents. Each agent runs sealed off from the server and from the internet. Today we set these up by hand; customers cannot create their own. | Shipped · set up at install |
| Chat for visitors and read-only viewers | Anyone you share a workspace with, and visitors to our own site, can ask questions in chat without an account or a key; it runs on an inexpensive model at no cost to them. *Chat for read-only viewers and visitors, on an inexpensive model, with 1.0.1.* | Scheduled · 1.0.1 |
| Import chats from ChatGPT or Claude | There is no way for a person to bring in their ChatGPT or Claude history. The only imported chats are a one-time copy, done by us, of chats from the older Sophia system. *Bring your team's ChatGPT and Claude histories in, in 1.2.* | Scheduled · 1.2 |
| Sophia's agents reach your systems (outbound tools and approved actions) | Sophia's own agents can look things up in your other systems and, with a person's approval, act there (create a ticket, post to a channel, draft a PO). *Letting Sophia's agents act in your other systems, with your approval on each kind of action, is planned after 1.2.* | Backlog |
| Use your ChatGPT plan for Sophia's chat | Sign in with your ChatGPT account so Sophia's chat runs on your own ChatGPT plan instead of on Sophia credits. *When OpenAI opens Sign in with ChatGPT to hosted apps generally.* | Backlog |
