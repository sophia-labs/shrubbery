# Sophia Desk

The shared workspace for your company's documents, files and knowledge, where your people and your agents work side by side.

- Documents several people edit at once
- Files up to 50 MB, previewed in the page
- Typed links between any two pages, with backlinks
- Full history, restore points and Trash

*Shipped · next release 1.0.1*

## Workspace

| Item | What it is | Status |
| --- | --- | --- |
| Search: titles and full text | Find a page by name or by any words inside it from one quick-search box. | Shipped |
| Version history and restore points | See earlier versions of any page, compare them and put an old version back. The whole workspace is also snapshotted automatically so it can be rolled back to an earlier moment. | Shipped |
| Comments | Highlight text and leave a comment, then resolve it when done. | Shipped |
| Appearance and phone layout | Pick a look for the workspace (including dark mode), and use it on a phone with a layout made for small screens. | Shipped |
| Files canvas and drawings | Lay out a folder's documents and files as cards on a whiteboard, arrange them, and draw labelled connections between them that are saved as real links. | Shipped |
| Files: store any file up to 50 MB with PDF and image preview | Upload any file (contracts, spec sheets, photos, spreadsheets) into a workspace folder. PDFs and pictures open right in the page; everything else downloads. | Shipped |
| Folders, one tree and Trash | Documents and files live together in one folder tree that you can filter by kind, drag around and nest. Deleting puts things in a Trash you can restore from. | Shipped |
| Shared documents with live co-editing | Write documents in the browser, and several people can edit the same page at once and see each other's cursors. Pages keep working if the connection drops and catch up when it returns. | Shipped |
| Typed links (wires) and backlinks | Link one paragraph or page to another with a meaning ('supports', 'contradicts', 'requires'), and see every link into and out of a page. | Shipped |
| Invitations by email, @mentions and notifications | Invite a colleague by typing their email, mention them in a page or comment, and have them told about it. *Invite a colleague by email, mention them, and notify them, in 1.1.* | Scheduled · 1.1 |
| Desktop edition (local-first Sophia Desk) | A Mac and Windows app that keeps a workspace entirely on the user's own computer, with no server. *A local-first desktop edition is planned after 1.2.* | Backlog |

## Data & export

| Item | What it is | Status |
| --- | --- | --- |
| Data export in open formats | A whole workspace downloads as one file in a standard data format that other software can read. Any single document downloads as Markdown or a styled web page (which prints to PDF), and any uploaded file downloads as the original. | Shipped |
| Structured records checked against rules | Besides free-form documents, agents and developers can store typed records (memories, workflows, file views). These are checked against declared rules, and bad records are blocked or flagged. | Shipped |
| Full take-out archive (everything, re-importable) | One download that contains every document, file, version and setting of a workspace, and that can be loaded back into Sophia, on our cloud or on yours. *A complete, re-importable take-out archive you can download yourself, in 1.1.* | Shipped · set up at install |
| Your own business data model | A company's own record types, such as Customer, Order or Supplier, can be declared once, and every record is then checked against them. | Shipped · set up at install |
| Personal data export and erasure | On request, give one person a copy of everything held about them, or erase them, including their chat history. *Export or erase one person's data on request, in 1.1.* | Scheduled · 1.1 |
